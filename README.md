# CV web · Uíliam Mateu

Mi currículum en formato web: objetivo profesional, formación (DAW, ASIX, SMX), experiencia y contacto.

**Demo:** https://wiliampsa11.github.io/cv/

## Tecnologías
- HTML5, CSS3 (Sass) y JavaScript
- Plantilla [Read Only de HTML5 UP](https://html5up.net/read-only) (licencia CCA 3.0) adaptada con mis datos
- Font Awesome y jQuery (incluidos en `assets/`)

## Estructura
```
index.html
assets/css, assets/sass, assets/js, assets/webfonts
img/
```
