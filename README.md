# CV web · Uíliam Mateu Martins

Mi currículum como desarrollador **Backend / Fullstack Junior** (PHP · Laravel · Python · SQL): perfil, experiencia, proyectos, formación, certificaciones e idiomas.

**Demo:** https://wiliampsa11.github.io/cv/

## Características
- HTML semántico y CSS propio, sin frameworks ni jQuery
- Diseño adaptado a móvil, tableta y escritorio
- Modo oscuro automático según el sistema
- Versión para imprimir en A4 y descarga del CV en PDF
- Datos estructurados (schema.org) y metadatos para compartir en redes
